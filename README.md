# Night in the Woods Co-op prototype

A BepInEx host/client prototype for the original Windows x64 Steam release of *Night in the Woods* (build 5940043, Unity 5.6.2p4, Mono). The public source now contains candidate v0.6.193. It is experimental software, not a finished or verified playable co-op mod.

In a fresh-save v0.6.190 same-PC loopback run, two isolated clients moved independent Maes with visible remote puppets and synchronized the BusStation opening, both Janitor `excuse` choices, Phone/reception and whosteals, VendingMachine, and the Mural `visitors`, `forest` and `mine` branches. Dialogue line events were acknowledged and tested story variables converged; a four-sample passive soak stayed connected and hash-matched. The Mural `wow` branch was covered in an earlier v0.6.143 run. This is bot-driven local evidence only. Another computer, normal player controls, LAN/VPN play, save/restart behavior, and a full story run are not verified. This repository contains source and instructions, not game data or a packaged release.

The remote Mae puppet uses a cool-blue tint at 72% alpha so it stays distinguishable when the two characters overlap. v0.6.174 was loaded in both isolated v018 QA copies; screenshots showed the tinted puppet on both clients, and a four-sample BusStation soak retained the connection and matching story hash `873001EE`. This is same-PC loopback QA, not verification of ordinary controls, LAN/VPN, or a full playthrough.

## Build

Build against the game's own managed assemblies and BepInEx 5.4.23.5:

```powershell
.\build.ps1 -GameDir 'C:\Games\Night in the Woods'
```

The build writes `NightInTheWoodsCoop.dll` and `NightInTheWoodsSavePathPatcher.dll` under `dist/`. Game files and compiled binaries are not included in this source repository.

## Install and connect

1. Install BepInEx 5 x64 in each player's own copy of the game.
2. Copy `NightInTheWoodsSavePathPatcher.dll` to `BepInEx/patchers/` and `NightInTheWoodsCoop.dll` to `BepInEx/plugins/`.
3. Configure one copy with `Role = Host` and the other with `Role = Client` in `BepInEx/config/coop-anything.nitw.cfg`.
4. Set the client's `HostAddress` to the host's LAN or VPN IPv4 address. Set the same UDP `Port` on both copies; allow that port through the host's firewall or use a VPN.
5. Start both copies at the same scene and story point.

The preloader redirects `Continuity` save paths to `BepInEx/config/NightInTheWoodsCoop/Saves` before the game assembly loads. The joining player's `Continuity.Save()` call is suppressed. Keep backups of existing saves before trying experimental software.
